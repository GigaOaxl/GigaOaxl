## 🛰️ Woran ich gerade baue

**[homserver-dashboard](https://github.com/GigaOaxl/homserver-dashboard)** — ein selbst gehostetes Kontrollzentrum:
Smart Home, Portfolio & FIRE, Tickets, Jellyfin, KI-Steuerung und Discord-Bot in einer ruhigen Oberfläche.

## 🧰 Stack

- **Backend:** PHP 8.3 · Laravel · Livewire · FastAPI
- **Infra:** Docker Compose · nginx · Ansible · WireGuard · MQTT
- **Frontend:** Bootstrap · Sass · Vite · Alpine.js
